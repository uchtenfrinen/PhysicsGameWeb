# Доска в задаче — что проверить

## Что нужно от тебя (если всё равно не рисует)

1. **Пересобери проект** после изменений (`Build` / `dotnet build`), **закрой** запущенный `.exe` перед сборкой (иначе ошибка копирования).
2. **Кликни по окну игры**, чтобы оно было в фокусе — иначе координаты мыши могут не обновляться.
3. Открой вкладку **«Доска»** в левой колонке, рисуй **в большой тёмной области справа** (не по боковой панели слева).
4. **Зажми ЛКМ** и **веди** по области доски — линия строится при движении; **C** очищает.

## Если не помогло

- Напиши: **окно** или **полный экран**, **масштаб Windows** (100% / 125% / 150%).
- Пришли **скрин** экрана с открытой доской (можно без личных данных).

Код доски: `Gameplay/Scenes/TaskScene.cs` — `RenderBoardDrawingToRenderTarget`, `BoardCanvasRect`.
